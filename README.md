# Portfólio · Maria Fernanda Moura Carrijo

Site em pastas (sobre mim, trabalhos, contato), feito a partir do layout no Figma.

- `index.html` — conteúdo do site
- `style.css` — visual e animações
- `script.js` — troca de pastas e animações; os links do currículo e do LinkedIn ficam no topo deste arquivo
- `assets/` — imagens exportadas do Figma
- `fonts/` — fonte Manrope

Para colocar um vídeo na seção de audiovisual, troque um `<div class="video r"></div>` no `index.html` por
`<div class="video r"><video src="assets/videos/nome.mp4" autoplay muted loop playsinline></video></div>`.
